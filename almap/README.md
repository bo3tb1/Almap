# ALmap V6.0 - Nmap Killer\n\nALmap is a high-performance network scanner written in Goose and C. It now features **623 compiled C plugins (AlScripts)**, surpassing Nmap's NSE library in quantity and including full ports of complex protocols like Heartbleed, EternalBlue, and Kerberos.\n\n## Features\n- Async epoll engine (--fast)\n- Advanced OS Fingerprinting (T1-T7)\n- 623 C Plugins (NSE ports)\n- Web UI\n\n## Rust Plugin Migration (in progress)\nThe plugin arsenal is being migrated from C to Rust for memory safety while preserving full protocol logic. Batch 1 (10 plugins) lives in `rust_plugins/` and shares a `#[repr(C)]` `AlScriptContext` ABI plus `#[no_mangle] extern \"C\" fn almap_script_run`, so the existing dlopen loader runs them unchanged. Build: `rustc --crate-type cdylib -O rust_plugins/<name>.rs -o rust_plugins/<name>.so`.\n- Batch 1: ssl-heartbleed-full, smb-vuln-ms17-010-full, kerberos-asreq-full, http-shellshock(+2), smb-enum-shares, ftp-proftpd-backdoor, ssh-hostkey, dns-zone-transfer, mysql-vuln-cve2012-2122, ms-sql-info.\n- Pure std (no external crates); the Heartbleed OpenSSL stage-1 handshake is dropped in favour of the pure-Rust raw-TLS probe.\n\n*Use only on networks you own or have permission to scan.*
