# ALmap V6.0 - Nmap Killer\n\nALmap is a high-performance network scanner written in Goose and C. It now features **623 compiled C plugins (AlScripts)**, surpassing Nmap's NSE library in quantity and including full ports of complex protocols like Heartbleed, EternalBlue, and Kerberos.\n\n## Features\n- Async epoll engine (--fast)\n- Advanced OS Fingerprinting (T1-T7)\n- 623 C Plugins (NSE ports)\n- Web UI\n\n*Use only on networks you own or have permission to scan.*
